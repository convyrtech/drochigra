# ВОСТОК-9: Смена в Бездне

Мобильная игра: копка вглубь + оборона купола + оффлайн-добыча.
Альтернативный 1987-й, Антарктида, станция «Восток-9» вскрыла Бездну.

Портретная ориентация, одна рука, смена 6 минут.

## Документы

- `docs/PLAN_V1.md` — что делаем сейчас (источник истины).
- `docs/GDD_VOSTOK9.md` — полный замысел, куда игра растёт.
- `AGENTS.md` — правила работы в репозитории.
- `content/balance.json` — все игровые числа, правятся без программиста.

## Статус

Разработка первой версии. Цель — публикация на itch.io, затем Google Play.

## Стек

TypeScript, Phaser 3, Vite, vitest. Позже Capacitor для Android.
