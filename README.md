# ВОСТОК-9: Смена в Бездне

Мобильная игра: копка вглубь + оборона купола + оффлайн-добыча.
Альтернативный 1987-й, Антарктида, станция «Восток-9» вскрыла Бездну.

Портретная ориентация, одна рука, смена 6 минут.

**Играть прямо сейчас:** https://convyrtech.github.io/drochigra/

Собирается автоматически: любой коммит в `main` через минуту оказывается на этой ссылке.

## Как править числа без программиста

Все игровые числа лежат в одном файле — `content/balance.json`. Здоровье купола, урон турели,
цены прокачки, добыча со слоёв, откат залпа. Правишь число, перезагружаешь страницу — работает
по-новому. Пересобирать ничего не надо, к коду прикасаться тоже.

Что означает каждое число — в `docs/PLAN_V1.md`. Там же в §6 записана **замеренная** форма
сложности обороны: её легко испортить случайной правкой, поэтому числа волн лучше менять,
сверяясь с этим разделом.

После правки — `npm run measure`. Это прогон настоящей игры ботом с нуля до дна Бездны: он
печатает таблицу доходности слоёв, куда уходит время смены, форму обороны и всю дугу по сменам —
и падает, если правка сломала обещание из плана (дно за 15–25 смен, покупка всегда в 40 секундах,
тишина между решениями 8–30 секунд под любой прокачкой, каждый слой богаче предыдущего на 15%).

Ёмкость карго и добыча со слоёв — связка, а не два независимых числа: `floor(карго / добыча)` даёт
число клеток в ходке, копка ходки — это тишина между решениями, а сдача ходки — это лом в минуту.
Одно число с двух сторон; крутить их порознь не выйдет, и почему — в `docs/PLAN_V1.md` §12.
Поэтому же ветка «Карго» поднимает ёмкость и добычу вместе: иначе одна покупка удлиняла бы тишину
скачком. По той же причине **пятилетка**, которая множит добычу, множит тем же числом и ёмкость.
Ёмкость карго при этом никогда не бывает меньше лома с клетки самого глубокого слоя — иначе бур
встал бы намертво.

## Как запустить у себя

```
npm install       # один раз
npm run dev       # игра на localhost, правки видны сразу
npm run test      # проверки логики
npm run measure   # прогон баланса: дуга до дна, доходность слоёв, форма обороны
npm run build     # папка dist/ — её же заливать на itch.io
```

## Документы

- `docs/GOAL_V1.md` — где финишная черта и как понять, что игра доделана.
- `docs/PLAN_V1.md` — что делаем сейчас (источник истины).
- `docs/GDD_VOSTOK9.md` — полный замысел, куда игра растёт.
- `AGENTS.md` — правила работы в репозитории.
- `content/balance.json` — все игровые числа, правятся без программиста.
