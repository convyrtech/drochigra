# AGENTS.md — правила работы в репозитории

## Что читать перед кодом

1. `docs/PLAN_V1.md` — что делаем сейчас. Источник истины для первой версии.
2. `docs/GDD_VOSTOK9.md` — большой замысел, куда игра растёт потом. Не реализуется целиком.

При конфликте побеждает `PLAN_V1.md`.

## Стек

TypeScript + Phaser 3 + Vite. Сборка — статика для itch.io. Google Play позже через Capacitor
из того же кода. Тесты — vitest.

## Структура

```
docs/            GDD_VOSTOK9.md, PLAN_V1.md
content/         balance.json — все игровые числа
src/sim/         чистая логика без графики, покрыта тестами
src/game/        сцены и отрисовка Phaser
src/ui/          интерфейс, кнопки, экраны
tests/           vitest
```

## Жёсткие правила

- **Числа только в `content/balance.json`.** Ни одной игровой константы в коде. Владелец проекта
  правит баланс сам, без программиста.
- **В `src/sim` запрещён `Math.random`.** Случайность только через сид, переданный снаружи.
  Одинаковый сид — одинаковая игра.
- **`src/sim` не знает про Phaser.** Никаких импортов графики в логику.
- Один шаг плана = один коммит. Не смешивать несвязанные изменения.
- Не рефакторить то, что не относится к текущей задаче.
- Не добавлять зависимости без явного согласования.
- Не реализовывать то, что в `PLAN_V1.md` перечислено в разделе «Чего нет».

## Правила игрового дизайна, которые нельзя нарушать кодом

Из `PLAN_V1.md` §2. Коротко: игрок не теряет сданное; проигрыша не существует, есть аварийный
подъём; каждая смена что-то добавляет; оффлайн даёт только лом.

## После каждой задачи

- `npm run test` — зелёный.
- Игра открывается в браузере и в неё можно играть.
- Скриншот или короткое описание, что именно изменилось на экране.

## Язык

Интерфейс и тексты игры — русский. Код, имена файлов, переменные, коммиты — английский.
